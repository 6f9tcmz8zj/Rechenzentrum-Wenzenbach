# Bürgerinitiative für Naturerhalt gegen Rechenzentrum
The project is designed for GitHub Pages and uses only HTML, CSS, and vanilla
JavaScript. 

## How to use

Once the static website files are present, it can be previewed with any local
static HTTP server. For example, from the repository root:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000> in a browser.
